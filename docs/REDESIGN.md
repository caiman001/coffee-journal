## 一、产品隐喻

**一台住在灵动岛里的小票打印机 + 一张摊满收藏的咖啡桌。**

- 记录一颗豆子 = 在打印机上录单、打出一张小票（仪式感核心）
- 豆子收藏 = 小票便签散落在画布上，随意拖拽布置，展示收集的满足感
- 打印机是工具，画布才是主页

## 二、交互模型（定稿 v10）

```
待机：灵动岛显示 ☕ N BEANS，整屏 = 便签画布
 └─ 按灵动岛 → 弹性展开成打印机（覆盖上方）
     ├─ 橙色亚克力屏 = NEW COFFEE 填单（默认态，无列表）
     │   字段：名称 / 产地 / 烘焙(三色点) / 粉量 / 液重 / 时间 / 研磨
     │   （比例自动计算，不用填）
     ├─ 按紫色 PRINT 键帽 → 直接出票：小票从出纸缝吐出（步进动画+蜂鸣）
     │   落到画布上，表单清空可连续录入
     └─ 再按机身 → 收回灵动岛
画布便签：
 ├─ 拖 = 挪位置（位移≥8px），拿起时摆正+影子加深，自动置顶
 └─ 点 = 编辑：小票放大居中+背景磨砂，全字段虚线格修改，
     烘焙度换色点（印章/色带联动），✓完成 或点空白保存弹回
```

## 三、视觉定稿

参考图：铬合金圆角方体 + 半透明糖果色亚克力（橙/紫/青）打印机，浅色摄影棚场景。

- **实现方式：手工 SVG 数字绘景**（约 200 行，viewBox 600×670），不用图片贴图、不用 WebGL
- **无描边原则**：所有"边"由相邻的高光/阴影塑形，杜绝矢量插画感的线条
- **圆角家族**：机身 R64 → 面板 R28-30 → 内台阶 R16，三级递减保证咬合
- **铬**：11 段高对比横向反射带 + 纵向受光 + 四转角独立受光斑 + feTurbulence 拉丝 + 右缘镜头光斑
- **亚克力配方**（三块面板同一套）：基色渐变 + 径向内透光 + 20px 模糊边缘变深 + 错位软影注塑台阶 + 顶缘高光 + 斜向反光 + 手放划痕 + 底部沉色 + 细颗粒
- **PRINT = 紫色键帽**：凸起体块（顶高光/底落影/双层刻字），按压整块下沉 5px
- **小票**：米黄热敏纸 + 纤维噪点 + 底部锯齿撕边（conic-gradient mask）+ 烘焙度印章与色带
- 场景：浅色摄影棚光，状态栏深色字；旧版暗黑玻璃风整体退役
